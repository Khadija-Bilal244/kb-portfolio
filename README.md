## ✨ Overview

This repo holds the source for my personal portfolio — a fully responsive, single-file site (`portfolio.html`) that introduces who I am, what I build, and the projects I've shipped across full-stack web dev, applied security, and machine learning.

No React, no Tailwind, no bundler. Just semantic HTML, custom CSS (Grid + Flexbox), and progressively-enhanced JS for the interactive bits — built this way on purpose, to keep it lightweight and fully under my control.

## 🎨 Design & UX highlights

- Custom dark "terminal-meets-editorial" theme — deep navy panels, teal/amber accents, JetBrains Mono + Space Grotesk + Fraunces type pairing
- Floating pill navbar with scroll-aware active-link indicator and animated hover pill
- Fully responsive: adaptive breakpoints down to small phones, with a slide-out mobile menu
- Scroll-triggered reveal animations, animated stat counters, infinite tech-stack marquee
- Respects `prefers-reduced-motion` for accessibility
- Custom cursor glow + subtle grain/texture overlay for depth

## 🛠️ Built with

`HTML5` · `CSS3 (Grid/Flexbox, custom properties)` · `Vanilla JavaScript` · `Google Fonts`

##  Running locally

No install, no dependencies:

```bash
git clone https://github.com/Khadija-Bilal244/<repo-name>.git
cd <repo-name>
open index.html
```

That's it — it's a static file, so any local server (or none at all) works fine.
